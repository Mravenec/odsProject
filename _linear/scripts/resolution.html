DB
MariaDB — tabla ods_login.ods_catalog
17 filas con icono_url = '/ods-icons/ods-NN.png', color_hex, nombre. Poblado por los INSERTs en 0.database/propuesta_actual/ods0N_database.sql.
-- Ejemplo ODS 1 INSERT IGNORE INTO ods_login.ods_catalog (id, nombre, color_hex, descripcion, icono_url) VALUES (@ODS_NUM, 'Fin de la Pobreza', '#E5243B', '...', '/ods-icons/ods-01.png');
BE
Backend — GET /api/catalog/ods
CatalogController hace fetchInto(OdsCatalog.class) y serializa el POJO JOOQ completo. Sin cambios de código en el sprint — solo necesitaba datos en BD.
// Respuesta JSON (ejemplo) { "id": 1, "nombre": "Fin de la Pobreza", "colorHex": "#E5243B", "iconoUrl": "/ods-icons/ods-01.png", "descripcion": "..." }
FE
Frontend — catalogService.getOdsList()
useCatalog() carga al montar. Mapea iconoUrl, colorHex, nombre → odsList en ProjectCreationPage.
// catalogService.js iconoUrl: o.iconoUrl || o.icono_url || null
UI
Grid — componente OdsSelectionCard
Patrón igual que ods.cr: backgroundColor + backgroundImage: url(iconoUrl). Si la imagen falla → fallback número + nombre.
// Estilo inline (patrón ods.cr #obj-item1 a) backgroundColor: ods.colorHex, backgroundImage: `url(${ods.iconoUrl})`, backgroundSize: '100%', backgroundRepeat: 'no-repeat'
PNG
Archivos estáticos — public/ods-icons/
Vite sirve en http://localhost:5173/ods-icons/ods-NN.png. Fuente: https://ods.cr/themes/custom/ods10/img/itemNN.png (grid oficial #items-objetivos).
